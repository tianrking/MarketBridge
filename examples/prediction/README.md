# Prediction markets / 预测市场

## English

These Python examples observe public market, book, trade and settlement data
for calibration and timing research. They do not place orders or sign wallets.

## 中文

这些 Python 示例只观察公开市场、订单簿、成交和结算数据，用于校准与时序研究；不下单、不签名钱包。
