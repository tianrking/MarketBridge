# Weather observations / 天气观察

## English

Weather examples compare public Open-Meteo observations with explicit market
and calibration inputs. They are deterministic research observers only.

## 中文

天气示例把公开 Open-Meteo 观测与明确的市场和校准输入做对照，只是确定性的研究观察器。
